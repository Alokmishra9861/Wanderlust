Wanderlust is a comprehensive full-stack web application that allows users to discover, list, and book unique accommodations around the world. From cozy cabins to luxury villas, the platform provides a seamless interface for travelers and property owners alike.

🌟 Features
Property Listings: Users can view detailed listings with descriptions, pricing, and locations.

User Authentication: Secure signup and login functionality for personalized experiences.

Create & Manage Listings: Host your own property by uploading images, setting prices, and providing details.

Interactive UI: A fully responsive design built for both mobile and desktop users.

Search & Filters: Easily find the perfect stay based on categories or location.

Review System: (If applicable) Users can leave feedback and ratings for properties they've visited.

🛠️ Tech Stack
Frontend: HTML5, CSS3, JavaScript (ES6+)

Styling: Bootstrap / Custom CSS

Backend: Node.js, Express.js

Database: MongoDB

Templating Engine: EJS (Embedded JavaScript)

Maps/Storage: Mapbox API (for locations) & Cloudinary (for image hosting)



Wanderlust/

├── public/         # Static assets (CSS, Client-side JS, Images)
├── routes/         # Express routes for listings, users, and reviews
├── utils/          # Middleware and error handling utilities
